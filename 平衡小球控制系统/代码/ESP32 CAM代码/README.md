# ESP32 CAM 图传模块

本目录包含运行在 XIAO ESP32-S3-Sense 上的 Arduino 源码。主要用于完成题目要求的“摆球位置监测图传”以及“录像与回放”功能。

## 🎯 功能特性
1. **双重网络模式**：支持 AP 模式（自建 WiFi 热点）或 Station 模式（连接现有路由器）。
2. **多线程服务**：
   - **抓帧任务 (FreeRTOS)**：在后台以 15fps 将 QVGA 图像从摄像头抓取至 PSRAM 的双缓冲中。
   - **HTTP 服务**：端口 81，提供实时 MJPEG 视频流（`/stream`），无阻塞。
3. **双重录制**：
   - **浏览器端录制**：利用 Web `MediaRecorder` API 将视频流保存为 WebM 文件下载到 PC。
   - **SD 卡原画直录**：调用 `/start_rec` 后，直接将无损 JPEG 帧写入 SD 卡，帧率稳定，不占用额外编码算力。
4. **视频回放**：
   - 访问 `/playback`，浏览器直接读取 SD 卡上的 JPEG 帧序列，以 15fps 播放，支持拖动进度条和倍速播放，完美满足赛事要求。

## 🔌 硬件接线（XIAO ESP32-S3-Sense）
本模块自带摄像头和 MicroSD 卡槽，无需外接大量外设：
- 只需接入 **5V/3.3V 供电** 即可独立运行。
- 摄像头置于摆杆正上方，俯视拍摄整个摆杆。

## 🛠️ 使用方法
1. 在 Arduino IDE 中安装 ESP32 支持包。
2. 选定板型为 `XIAO_ESP32S3` 并开启 PSRAM。
3. 编译烧录 `camera.ino`。
4. 手机或 PC 连接 WiFi `YouAreGay` (密码 `12345678`)。
5. 浏览器访问 `http://192.168.4.1:81`，点击“SD 开始录制”即可记录比赛画面。比赛结束后进入回放页面进行展示。
