# 循迹小车底盘控制系统

本工程为 26 电赛 730 题小车底盘的 STM32F103VET6 控制代码。负责完成场地的循迹、不同距离的跑圈（第2、4、5、6项）以及高精度定点缓停。

## 🎯 系统职责
由于本项目分为两块 MCU 控制，本 MCU **仅负责底盘行驶**，不参与摆杆平衡控制。
主要功能：
1. **路况感知**：读取 8 路数字灰度传感器，识别直线、弯道与起停线。
2. **精准循迹**：通过位置 PID 对差速轮进行控制，保证车体严格在黑线正上方。
3. **距离与速度闭环**：通过编码器获取实时速度与累计里程，支持特定距离（AB段）的闭环行驶。
4. **停车算法**：结合“特征路口（灰度跳变）”与“最短行驶时间屏蔽（RunTime_ms）”，实现抗干扰的一圈定点停车，误差在 2cm 以内。

## 📂 核心代码说明
- `User/main.c`：主循环，处理任务按键切换与 OLED 显示，TIM1 10ms 中断入口。
- `Hardware/Track.c`：循迹 PID 控制，将灰度数据转化为小车转向 PWM 差值。
- `Hardware/Encoder.c`：基于定时器正交解码的编码器测速，并累加得到 `Actual_Location`。
- `Hardware/Motor.c & PWM.c`：底层 L298N/TB6612 电机驱动，包含缓启动（Car_Accel）逻辑。
- `Track/Track.c`：针对不同任务的特定逻辑封装，例如 `Track_Control_loop_30()` 负责跑完 30cm 赛道后触发停车。

## 🛠️ 任务模式切换
上电后，通过按键 2 (Key2) 在三种状态间切换：
- `loop_20`：针对直径 20cm 或内圈的跑圈任务。
- `loop_30`：针对常规一圈测试任务，起步后最少行驶 `RUN_TIME_MIN_SEC_loop30` 秒才允许识别 A 点停车线。
- `AB`：两点直线定距跑任务，通过累计距离自动缓停。
按下 Key1 即可启动或停止当前任务。

> **注意**：底盘与摆球系统在上层并未做硬连线握手，实际测试时由操作手同时按下两板的运行键。
