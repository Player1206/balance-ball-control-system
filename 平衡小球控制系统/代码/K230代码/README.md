# K230 视觉模块

本目录包含运行在嘉楠 K230 视觉模块上的 MicroPython 脚本，用于实现对摆杆上钢球的 1D 位置识别与速度估算。

## 🎯 功能特性
1. **高帧率识别**：配置 Sensor 工作在 640x480 分辨率，实际帧率可达 ~90fps。
2. **标定模式**：开机进入标定状态，可通过外接按键（KEY0/KEY1）动态调节灰度阈值，并在屏幕上实时预览二值化效果。
3. **精准 ROI 提取**：在窄长条区域（575x35）内进行 `find_blobs` 检测，结合长宽比与面积过滤，精准定位钢球中心。
4. **EMA 速度平滑**：引入指数移动平均（EMA，α=0.85）对小球坐标进行平滑，同时计算实时速度（cm/s）。
5. **UART 数据输出**：通过 UART1（115200bps）向外（STM32）发送 `S,x,v,flag\n` 格式的实时数据。

## 🔌 硬件接线（正点原子 K230D）
- **UART1_TX**：GPIO 40 -> STM32 UART4_RX
- **UART1_RX**：GPIO 41 -> STM32 UART4_TX
- **KEY0** (减小阈值)：GPIO 34
- **KEY1** (增大阈值)：GPIO 35
- **KEY2** (确认进入运行态)：GPIO 0

## 🛠️ 使用方法
1. 将 `main.py` 烧录或拖入 K230 的存储区。
2. 上电后屏幕显示二值化画面。
3. 使用 KEY0 和 KEY1 调节阈值，使钢球被稳定识别（显示红框）。
4. 同时按下 KEY0, KEY1 (或单按 KEY2 视接线) 退出标定，进入追踪模式，通过串口向 STM32 持续发送数据。

## 📝 通信协议
- 格式：`S,<X_cm>,<V_cm/s>,<flag>\n`
- `flag`: 1表示检测到球，0表示丢球（丢球时保持上次坐标，速度为0）。
- 例如：`S,12.34,3.50,1\n`
